# No third-party code is loaded until an isolated extension system is designed

The reference product loads third-party extensions without a build step, inside the page. In a product whose private rooms promise end-to-end encryption, code from elsewhere in the page can read the key. Extensions are wanted by the owner and come last, after their own study, running isolated from the page that holds keys and media. Until then every feature is first-party and the content security policy allows only our own origin.

Delivery order agreed on 2026-11-16: (1) lobby, rooms, presence, screen with system audio, microphone, camera, chat, people, owner controls; (2) voice filter, push to talk, per-person volume, layouts, pin, cinema, picture-in-picture, zoom, reactions, raised hand, statistics, command palette; (3) end-to-end encryption of private rooms; (4) transcript and local audio recording; (5) whiteboard and camera effects; (6) extensions.
